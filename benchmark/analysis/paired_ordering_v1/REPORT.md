# Matched size-ordering ablation

The balanced cohort contains 140 paired runs: 28 parameter settings with five identical seed orders per algorithm.

- Median absolute count error was lower with size ordering for 18/28 settings, equal for 3, and higher for 7.
- Median correct-cell F1 was higher with size ordering for 23/28 settings, equal for 3, and lower for 2.
- 4 planned settings were excluded because one or both algorithms produced no valid segmentation.

This matched ablation isolates ordering. The exact-count frequencies at the separately selected method settings answer a different, selection-level question.
